# MEC-043 Rolling Friction（滚动摩擦）

圆形刚体在水平面上纯滚动，受滚动阻力矩作用减速直至停止。与 MEC-024 纯滚动
对照，此处引入耗散。

## 物理背景

滚动摩擦不是接触面间的滑动摩擦，而是由于接触面微小变形产生的阻力矩。
滚动阻力矩 τ_r = μ_r·N·R，等效平动力 F_r = -μ_r·m·g·sign(v)。

**假设**：
- 纯滚动约束 v = R·ω 始终保持
- 滚动摩擦系数 μ_r ≥ 0（无量纲）
- 水平面，法向力 N = m·g
- 无滑动摩擦（理想纯滚动）

## 与已有 MEC 模型的关系

| 关系 | 说明 | 严格性 |
|------|------|--------|
| μ_r→0 → MEC-024 纯滚动 | 无耗散纯滚动 | ✓ 严格退化 |
| 有效质量 m_eff = m + I/R² | 同 MEC-024 | ✓ 概念复用 |
| 滚动阻力 -μ·N·sign(v) | 类比 MEC-041 动摩擦 | ✓ 数学结构相似 |

## 数学模型

### 滚动摩擦力

$$F_r = -\mu_r\,m\,g\,\text{sign}(v)$$

### 运动方程

$$m_{\text{eff}}\,\ddot{x} = -\mu_r\,m\,g\,\text{sign}(v)$$

$$\ddot{x} = -\frac{\mu_r\,m\,g}{m + I/R^2}\,\text{sign}(v)$$

### 解析解

$$t_{\text{stop}} = \frac{|v_0|\,m_{\text{eff}}}{\mu_r\,m\,g}, \quad x_{\text{stop}} = \frac{v_0^2\,m_{\text{eff}}}{2\,\mu_r\,m\,g}$$

## 状态空间表示

```
state = [x, v]
```

- `x` — 质心位移（m）
- `v` — 质心速度（m/s）

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `m` | 质量 (kg) | `1.0` |
| `R` | 半径 (m) | `0.5` |
| `I` | 转动惯量 (kg·m²) | `0.4·m·R²` (实心球) |
| `g` | 重力加速度 (m/s²) | `9.81` |
| `mu_r` | 滚动摩擦系数 | `0.01` |
