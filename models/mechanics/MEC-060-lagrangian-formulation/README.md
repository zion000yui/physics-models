# MEC-060 Lagrangian Formulation（拉格朗日力学公式化）

用拉格朗日方程重新求解已有模型，验证与牛顿法结果一致，建立分析力学框架。

## 物理背景

拉格朗日力学以能量（标量）为基础，通过欧拉-拉格朗日方程描述系统运动。
对约束系统（如双摆）优势明显：无需显式计算约束力。

### 核心方程

$$L = T - V \quad \text{(拉格朗日量)}$$

$$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i} - \frac{\partial L}{\partial q_i} = Q_i \quad \text{(欧拉-拉格朗日方程)}$$

### 重新求解的已有模型

| 模型 | L | 方程 | 验证 |
|------|---|------|------|
| MEC-001 自由质点 | ½mẋ² | mẍ=0 | ✓ 动量守恒 |
| MEC-002 受力质点 | ½mẋ²-Fx | mẍ=F | ✓ 匀加速 |
| MEC-010 弹簧振子 | ½mẋ²-½kx² | mẍ+kx=0 | ✓ ω=√(k/m) |
| MEC-011 阻尼振子 | ½mẋ²-½kx²+Q | mẍ+cẋ+kx=0 | ✓ 欠阻尼 |
| MEC-006 胡克力2D | ½m(ẋ²+ẏ²)-½k(x²+y²) | mẍ=-kx | ✓ 方向独立 |
| MEC-013 双摆 | T-V(θ₁,θ₂,θ̇₁,θ̇₂) | 非线性耦合 | ✓ 能量守恒 |

### Noether 定理

平移对称性 → 动量守恒：$\partial L / \partial \dot{x} = m\dot{x} = p$（自由质点）
