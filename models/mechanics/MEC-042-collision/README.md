# MEC-042 Collision（碰撞）

两个质点沿直线运动发生一维正碰撞。使用恢复系数 e 描述碰撞弹性程度，
分析动量守恒和能量变化。

## 物理背景

碰撞是瞬时事件，速度发生跳变。动量始终守恒，但动能是否守恒取决于恢复系数。
恢复系数 e = 1 为完全弹性碰撞（动能守恒），e = 0 为完全塑性碰撞（粘合）。

**假设**：
- 一维正碰撞（对心碰撞）
- 碰撞瞬时完成（无持续时间）
- 质量 `m1, m2 > 0`，恢复系数 `0 ≤ e ≤ 1`
- 碰撞前后自由运动

## 与已有 MEC 模型的关系

| 关系 | 说明 | 严格性 |
|------|------|--------|
| 碰撞前后自由运动 | MEC-001 自由质点 | ✓ 特例 |

## 数学模型

### 碰撞后速度

$$v_{1a} = \frac{m_1 v_{1b} + m_2 v_{2b} + m_2 e (v_{2b} - v_{1b})}{m_1 + m_2}$$

$$v_{2a} = \frac{m_1 v_{1b} + m_2 v_{2b} + m_1 e (v_{1b} - v_{2b})}{m_1 + m_2}$$

### 动能损失

$$\Delta T = -\frac{1}{2}(1 - e^2)\,m_{\text{red}}\,(v_{1b} - v_{2b})^2$$

其中 $m_{\text{red}} = \frac{m_1 m_2}{m_1 + m_2}$。

## 状态空间表示

```
state = [x1, v1, x2, v2]
```

- `x1, v1` — 质点 1 位置和速度
- `x2, v2` — 质点 2 位置和速度

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `m1` | 质点 1 质量 (kg) | `1.0` |
| `m2` | 质点 2 质量 (kg) | `2.0` |
| `e` | 恢复系数 | `0.8` |
