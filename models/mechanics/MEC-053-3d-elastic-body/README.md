# MEC-053 3D Elastic Body（三维弹性体）

三维线弹性体力学：广义胡克定律。从一维梁→二维板→三维弹性体的完整递进。

## 物理背景

各向同性线弹性体在小变形下的应力-应变关系。状态变量：位移 u、应变 ε（6 分量）、
应力 σ（6 分量），通过广义胡克定律关联。

### 广义胡克定律（本构关系）

$$\sigma_{ij} = 2G\varepsilon_{ij} + \lambda \varepsilon_{kk}\delta_{ij}$$

Lamé 参数：$\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}$, $G = \frac{E}{2(1+\nu)}$

### 弹性常数关系

| 常数 | 公式 | 物理意义 |
|------|------|---------|
| $G$ | $E/[2(1+\nu)]$ | 剪切模量 |
| $K$ | $E/[3(1-2\nu)]$ | 体积模量 |
| $\lambda$ | $E\nu/[(1+\nu)(1-2\nu)]$ | Lamé 第一参数 |

约束：$0 \le \nu < 0.5$（$K>0$ 稳定材料）

### 经典均匀应力状态

| 状态 | 公式 | 能量密度 |
|------|------|---------|
| 单轴拉伸 | $\varepsilon = \sigma/E$, $\varepsilon_\perp = -\nu\sigma/E$ | $U = \sigma^2/(2E)$ |
| 静水压缩 | $\theta = -p/K$ | $U = p^2/(2K)$ |
| 纯剪切 | $\gamma = \tau/G$ | $U = \tau^2/(2G)$ |

### 弹性波速

纵波（P波）：$c_p = \sqrt{(\lambda+2G)/\rho}$

横波（S波）：$c_s = \sqrt{G/\rho}$

波速比：$c_p/c_s = \sqrt{2(1-\nu)/(1-2\nu)} > \sqrt{2}$

## 与已有 MEC 模型的关系

| 关系 | 说明 | 严格性 |
|------|------|--------|
| MEC-050 梁 EI=E·bh³/12 | E 的一维特例 | ✓ 一维退化 |
| MEC-051 板 D=Eh³/[12(1-ν²)] | 平面应力特例 | ✓ 二维退化 |

| ν→0 | 各方向独立无耦合 | ✓ 物理退化 |

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `E` | 杨氏模量 (Pa) | `2.0e11` (钢) |
| `nu` | 泊松比 | `0.3` |
| `rho` | 密度 (kg/m³) | `7850.0` (钢) |
