# MEC-001 Free Particle（自由质点）

自由质点：不受外力、无约束的点质量。这是整个仓库里最简单的模型，
用来验证「模型定义 → 引擎求解 → 解析解对照」的最小闭环。

## 自由质点定义

自由质点是指不受任何外力、也不受约束的理想质点。

它的运动由牛顿第一定律决定：在惯性参考系中，速度保持不变，沿直线做匀速运动。

数学上：

$$
F = 0
$$

根据牛顿第二定律：

$$
ma = F
$$

因此：

$$
a = 0
$$

也就是：

$$
\frac{dv}{dt} = 0
$$

所以速度是常量：

$$
v(t) = v_0
$$

再由：

$$
\frac{dx}{dt} = v
$$

积分得到：

$$
x(t) = x_0 + v_0 t
$$

自由质点在惯性参考系中，若初速度为零，则保持静止；若初速度不为零，则沿初速度方向做匀速直线运动。

其实从物理上看，静止可以理解为速度为零的“特殊匀速直线运动”。因此更统一的说法是：

自由质点保持速度矢量不变。

## 物理模型

- 状态：位置 `x`、速度 `v`
- 一阶常微分方程：

  ```
  dx/dt = v
  dv/dt = 0
  ```

- 解析解（正确性金标准）：

  ```
  x(t) = x0 + v0 * t
  v(t) = v0
  ```
