# MEC-040 Rigid Contact（刚性接触）

质点在重力作用下与刚性地面发生法向单点接触。采用惩罚法（spring-damper）
建模法向接触力，实现接触/分离状态切换。是接触力学的最基本模型。

## 物理背景

质点从高处自由下落，接触地面后被弹回。接触力用惩罚法建模：当质点穿透
地面（y<0）时，产生与穿透深度成正比的恢复力（刚度 k_c）和与速度成正比
的阻尼力（阻尼 c_c）。

**假设**：
- 质点质量 `m > 0`
- 重力加速度 `g > 0`，沿 y 轴负方向
- 地面在 y=0，刚性不可贯穿
- 接触力只能推（法向），不能拉
- 惩罚参数：`k_c > 0`（接触刚度），`c_c ≥ 0`（阻尼）

## 与已有 MEC 模型的关系

| 关系 | 说明 | 严格性 |
|------|------|--------|
| 无接触时退化为自由下落 | MEC-002/MEC-003 重力分量 | ✓ 严格退化（参数极限）|
| 接触力是约束力 | MEC-024 静摩擦也是约束力 | ✓ 概念相似 |
| 无严格退化到 MEC-001 | 自由质点需同时去重力和去地面 | 需双条件 |

## 数学模型

### 接触力

$$F_{\text{contact}} = \begin{cases} \max(0,\, -k_c\,y - c_c\,\dot{y}) & y < 0 \\ 0 & y \geq 0 \end{cases}$$

### 运动方程

$$m\,\ddot{y} = -m\,g + F_{\text{contact}}$$

- 自由飞行（y > 0）：$\ddot{y} = -g$
- 接触（y < 0）：$\ddot{y} = -g + F_{\text{contact}}/m$

### 互补约束

$$F \geq 0, \quad g \geq 0, \quad F \cdot g = 0$$

### 自由飞行段解析解

$$y(t) = y_0 + v_0\,t - \frac{1}{2}g\,t^2, \quad v(t) = v_0 - g\,t$$

## 状态空间表示

```
state = [y, v]
```

- `y` — 质点高度（m，y=0 为地面）
- `v` — 质点速度（m/s，向上为正）

## 能量

| 条件 | 守恒量 |
|------|--------|
| c_c=0 | E = ½mv² + mgy + ½k_c·max(0,-y)² = const |
| c_c>0 | E 单调递减（接触耗散）|

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `m` | 质点质量 (kg) | `1.0` |
| `g` | 重力加速度 (m/s²) | `9.81` |
| `k_c` | 接触刚度 (N/m) | `1e4` |
| `c_c` | 接触阻尼 (N·s/m) | `0.0` |
