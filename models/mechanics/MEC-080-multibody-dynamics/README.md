# MEC-080 Multibody Dynamics（多体动力学）

综合刚体动力学 + 约束 + 分析力学的通用多刚体系统框架。以 N 连杆平面链为典型实例。

## 物理背景

N 刚体通过铰链连接成平面链，使用拉格朗日法自动推导运动方程。

### 运动方程（标准操作臂形式）

$$M(\theta)\ddot{\theta} + C(\theta, \dot{\theta})\dot{\theta} + G(\theta) = 0$$

| 矩阵 | 含义 | 维度 |
|------|------|------|
| $M(\theta)$ | 质量矩阵（惯性） | $N \times N$ |
| $C(\theta, \dot{\theta})$ | 科氏/离心力 | $N \times N$ |
| $G(\theta)$ | 重力向量 | $N \times 1$ |

### 质量矩阵（质心在杆中点 l/2）

$$M_{ij} = \sum_{k=\max(i,j)}^{N-1} m_k \cdot r_{ki} \cdot r_{kj} \cdot \cos(\theta_i - \theta_j) + \delta_{ij} I_i$$

其中 $r_{ki} = l_i$（$k > i$）或 $l_i/2$（$k = i$）。

### 退化验证

| N | 退化到 | 关键结果 |
|---|--------|---------|
| 1 | 单摆（质心 l/2） | $\ddot\theta = -(g/r)\sin\theta$, $r=l/2$ |
| 2 | 双摆 | $M_{11} = m_1(l_1/2)^2 + m_2 l_1^2$ 等 |

## 与已有 MEC 模型的关系

| 关系 | 说明 |
|------|------|
| MEC-020-024 刚体 → MEC-080 | 单体 → 链 |
| MEC-030 机构 → MEC-080 | 约束系统 |
| MEC-040 接触 → MEC-080 | 可扩展含接触 |
| MEC-060/062 分析力学 → MEC-080 | 拉格朗日自动推导 |
| MEC-080 → MEC-090 | 多体混沌 |

**注意**：MEC-080 使用质心在杆中点（l/2）的模型，与 MEC-060 的杆端质点双摆物理模型不同，两者均为正确但不同的系统。

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `masses` | 各杆质量 (kg) | `[1.0, 1.0, ...]` |
| `lengths` | 各杆长度 (m) | `[1.0, 0.8, ...]` |
| `inertias` | 各杆转动惯量 (kg·m²) | `[0.0, ...]` |
| `g` | 重力加速度 (m/s²) | `9.81` |

## 文件说明

| 文件 | 作用 |
