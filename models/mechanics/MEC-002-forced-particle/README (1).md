# MEC-002 Forced Particle（受恒定外力作用的质点）

受恒定外力作用的质点：质量为 m 的质点，受恒定外力 F 作用（F 为标量常数，
方向和大小都不随时间变化）。这是 MEC-001 自由质点的自然推广——加速度
从 0 变为 F/m，用来验证「模型定义 → 引擎求解 → 解析解对照」闭环在
非零外力下仍然成立。

## 物理模型

- 状态：位置 `x`、速度 `v`
- 参数：外力 `F`（恒定标量）、质量 `m`
- 一阶常微分方程：

  ```
  dx/dt = v
  dv/dt = F / m
  ```

- 解析解（正确性金标准）：

  ```
  x(t) = x0 + v0 * t + 0.5 * (F/m) * t²
  v(t) = v0 + (F/m) * t
  ```

## 文件说明

| 文件 | 作用 |
|---|---|
| `model.py` | 引擎无关：动力学方程 `dynamics` + 解析解 `analytical` |
| `scipy_solve.py` | 用 SciPy `solve_ivp` 做数值积分并打印误差 |
| `test_consistency.py` | 数值解 vs 解析解一致性测试 |

## 运行

```bash
python scipy_solve.py
python test_consistency.py
```

## 依赖

- numpy
- scipy

## 数值验证

以 `x0=0, v0=2, F=1, m=1, t_end=10` 为例，`scipy_solve.py` 输出：

```
时间点数      : 101
初始状态 [x,v]: [0.000000, 2.000000]
末点数值 x    : 70.000000
末点解析 x    : 70.000000
末点数值 v    : 12.000000
末点解析 v    : 12.000000
最大位置误差  : 1.421e-14
最大速度误差  : 2.665e-15
```

验证：x(10) = 0 + 2×10 + 0.5×(1/1)×10² = 70，v(10) = 2 + (1/1)×10 = 12，
数值解与解析解吻合，误差在机器精度量级。
