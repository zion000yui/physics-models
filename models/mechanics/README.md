# mechanics

力学模型集合，统一使用 `MEC-XXX-<description>` 命名。

## 编号分组

- MEC-001~009：质点运动与动力学（Point Particle Mechanics）
- MEC-010~015：振动与单摆（Oscillatory Systems）
- MEC-020~024：刚体运动（Rigid Body Dynamics）
- MEC-030~033：连杆机构（Mechanisms）
- MEC-040~043：接触、摩擦与碰撞（Contact & Impact）
- MEC-050~053：结构力学（梁/板/壳/三维弹性体）
- MEC-060~062：分析力学（拉格朗日/哈密顿/约束）
- MEC-080：多体动力学（Multibody Dynamics）
- MEC-090：非线性力学（Nonlinear Mechanics）
- MEC-100：弹塑性力学（Elastoplasticity）

共 38 个模型，全部已完成。
