# MEC-030 Four-Bar Linkage（四连杆机构）

平面四连杆机构：四根刚性杆通过四个转动副连接形成闭环。曲柄绕固定铰旋转，
通过连杆驱动摇杆。是最简单的闭环低副机构，引入闭环运动学约束和等效惯量动力学。

## 物理背景

四连杆由固定杆（l₁, 机架）、曲柄（l₂, 输入）、连杆（l₃, 耦合件）、摇杆（l₄, 输出）
组成。O₂ 和 O₄ 为固定铰。给定曲柄角 θ₂，连杆角 θ₃ 和摇杆角 θ₄ 由闭环约束唯一确定
（有两个构型分支：open 和 crossed）。

**假设**：
- 所有杆为刚性，无变形
- 运动副为理想转动副（无间隙、无摩擦）
- 平面运动（2D）
- 杆长 `l1, l2, l3, l4 > 0`
- 各杆质量 `m2, m3, m4 ≥ 0`，转动惯量 `I2, I3, I4 ≥ 0`
- 质心到近端铰距离 `r2, r3, r4`（默认 l/2，均匀杆）

## 与已有 MEC 模型的关系

| 关系 | 说明 | 严格性 |
|------|------|--------|
| 每根杆是 MEC-022 类型刚体 | 2D 平面运动 | ✓ 概念复用 |
| 曲柄/摇杆绕固定铰转动 | MEC-021 概念 | ✓ 概念复用 |
| 约束减少自由度 | MEC-024 纯滚动概念相似 | ✓ 概念复用 |
| 闭环约束 | **新概念**，不在任何已有模型中 | — |

**无严格退化到任何已有 MEC 模型。** 四连杆引入闭环运动学约束这一全新物理概念。

**与 MEC-031 曲柄滑块的关系**：曲柄滑块与四连杆具有数学上的极限联系
（l₄→∞ 时摇杆弧趋近直线），但由于 RRRR→RRRP 导致约束拓扑发生变化，
因此**不是严格退化**。

## 数学模型

### 坐标系

O₂ 在原点 (0, 0)，O₄ 在 (l₁, 0)。角度从 x 轴逆时针计量。

### Freudenstein 方程

$$K_1 \cos\theta_4 - K_2 \cos\theta_2 + K_3 = \cos(\theta_2 - \theta_4)$$

其中 $K_1 = l_1/l_2$, $K_2 = l_1/l_4$, $K_3 = (l_1^2 + l_2^2 - l_3^2 + l_4^2)/(2l_2 l_4)$

半角代换求解 θ₄：$\theta_4 = 2\arctan\frac{B \pm \sqrt{A^2+B^2-C^2}}{A+C}$

### 速度分析

$$\frac{\omega_3}{\omega_2} = \frac{l_2 \sin(\theta_2-\theta_4)}{l_3 \sin(\theta_4-\theta_3)}, \quad \frac{\omega_4}{\omega_2} = \frac{l_2 \sin(\theta_2-\theta_3)}{l_4 \sin(\theta_4-\theta_3)}$$

### 等效惯量动力学

$$I_{\text{eff}}(\theta_2)\,\alpha_2 + \frac{1}{2}I_{\text{eff}}'(\theta_2)\,\omega_2^2 + \frac{dV}{d\theta_2} = \tau$$

$$I_{\text{eff}} = I_{2,O_2} + m_3(l_2^2 + r_3^2 R_3^2 + 2l_2 r_3 R_3 \cos(\theta_2-\theta_3)) + I_3 R_3^2 + I_{4,O_4} R_4^2$$

其中 $R_3 = \omega_3/\omega_2$, $R_4 = \omega_4/\omega_2$,
$I_{2,O_2} = I_2 + m_2 r_2^2$, $I_{4,O_4} = I_4 + m_4 r_4^2$。

**动力学 ODE 无闭式解析解**（变等效惯量），通过数值积分 + 能量守恒验证。

## 状态空间表示

```
state = [theta2, omega2]
```

- `theta2` — 曲柄角度（rad）
- `omega2` — 曲柄角速度（rad/s）

系统为 1 自由度：θ₃, θ₄ 由 θ₂ 唯一确定。

## Grashof 判据

$$s + l \leq p + q$$

（s = 最短杆, l = 最长杆, p, q = 其余两杆）

满足时至少一根杆可整周转动。类型取决于哪根杆最短且哪根杆固定。

## 极限位置（Toggle）

曲柄与连杆共线时摇杆角速度 ω₄ = 0：
- 伸展极限：|O₂B| = l₂ + l₃
- 折叠极限：|O₂B| = |l₂ - l₃|

## 守恒量

| 条件 | 守恒量 |
|------|--------|
| τ=0, g=0 | E = ½·I_eff·ω₂² = const |
| τ≠0, g=0 | ΔE = τ·Δθ₂（功-能定理）|
| g>0 | E = ½·I_eff·ω₂² + V = const（τ=0 时）|

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `l1` | 固定杆长度 (m) | `2.0` |
| `l2` | 曲柄长度 (m) | `0.5` |
| `l3` | 连杆长度 (m) | `1.5` |
| `l4` | 摇杆长度 (m) | `1.2` |
| `m2, m3, m4` | 各杆质量 (kg) | `1.0` |
| `r2, r3, r4` | 质心距离 (m) | `l/2` |
| `I2, I3, I4` | 转动惯量 (kg·m²) | `m·l²/12` |
| `g` | 重力加速度 (m/s²) | `0.0` |
| `tau` | 输入力矩 (N·m) | `0.0` |
| `config` | 构型 | `'open'` |
