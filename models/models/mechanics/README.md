# Mechanics Models

This directory contains structured mechanics models.

Models are identified using the MEC numbering system.

## Categories

- MEC-001–009: Particle mechanics
- MEC-010–019: Oscillations
- MEC-020–029: Rigid-body mechanics
- MEC-030–039: Mechanisms
- MEC-040–049: Contact and friction
- MEC-050–059: Continuum mechanics
- MEC-060–069: Fluid mechanics
- MEC-070–079: Coupled mechanics
- MEC-080–089: Multibody dynamics
- MEC-090–099: Nonlinear mechanics
- MEC-100+: Advanced mechanics
